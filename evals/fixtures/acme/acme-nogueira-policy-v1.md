# Nogueira — Organização de arquivos vetoriais

Este procedimento fictício é exclusivo da operação Nogueira da Acme. Não se aplica a outras operações nem a outras organizações.

## Revisão 1

Cada pacote de arquivos vetoriais contém até 14 desenhos.

O índice do pacote informa a unidade de medida de cada desenho.

## Exceções

Exceções a este procedimento seguem o código ROUTE-NOGUEIRA. Consulte o registro separado para identificar o destino.
