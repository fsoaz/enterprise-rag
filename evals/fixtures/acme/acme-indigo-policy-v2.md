# Indigo — Simulation checkpoints

This fictional procedure applies only to Acme's Indigo operation. It does not govern other operations or organizations.

## Revision 2

Long simulations save a checkpoint every 15 minutes.

The simulation owner verifies the restart file before deleting scratch data.

## Exceptions

Exceptions to this procedure use routing code ROUTE-INDIGO. Consult the separate register to identify the destination.
