# Alder — Thermal camera loans

This fictional procedure applies only to Acme's Alder operation. It does not govern other operations or organizations.

## Revision 2

A thermal camera loan includes 3 spare memory cards.

Borrowers return the lens cap in the padded case.

## Exceptions

Exceptions to this procedure use routing code ROUTE-ALDER. Consult the separate register to identify the destination.
