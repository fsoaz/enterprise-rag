# Gorse — Demonstration equipment packing

This fictional procedure applies only to Acme's Gorse operation. It does not govern other operations or organizations.

## Revision 1

A demonstration crate contains at most 9 modules.

Each module is separated by a reusable foam divider.

## Exceptions

Exceptions to this procedure use routing code ROUTE-GORSE. Consult the separate register to identify the destination.
