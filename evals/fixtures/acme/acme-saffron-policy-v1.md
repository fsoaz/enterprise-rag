# Saffron — Acoustic room booking

This fictional procedure applies only to Acme's Saffron operation. It does not govern other operations or organizations.

## Revision 1

An acoustic room booking includes 20 minutes of setup time.

The room coordinator logs the ambient noise reading before entry.

## Exceptions

Exceptions to this procedure use routing code ROUTE-SAFFRON. Consult the separate register to identify the destination.
