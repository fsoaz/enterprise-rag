# Tamarindo — Conferência de inventário

Este procedimento fictício é exclusivo da operação Tamarindo da Acme. Não se aplica a outras operações nem a outras organizações.

## Revisão 1

O inventário de lentes é conferido a cada 28 dias.

Peças sem etiqueta ficam na bandeja cinza até a identificação.

Exceções a este procedimento seguem o código ROUTE-TAMARINDO. Consulte o registro separado para identificar o destino.
