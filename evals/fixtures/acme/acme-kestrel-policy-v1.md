# Kestrel — Dataset labeling reviews

This fictional procedure applies only to Acme's Kestrel operation. It does not govern other operations or organizations.

## Revision 1

A labeling batch must include 6 independently reviewed examples.

Disagreements are recorded in the silver adjudication log.

## Exceptions

Exceptions to this procedure use routing code ROUTE-KESTREL. Consult the separate register to identify the destination.
